    How the Agent Works

    1
    Data Fetching (MCP)

    Pulls raw transactions and source code via Etherscan / BscScan RPC endpoints.

    2
    Feature Transformation

    NetworkX converts the fund flow into degree centrality, clustering & flow metrics.

    3
    AST Vulnerability Scan

    Static analysis flags hidden mint functions, owner backdoors & blacklist traps.

    4
    Inference & Synthesis

    CatBoost emits a fraud probability, weighted with AST findings into one risk score.

    Why Recall Matters

    The cost of a False Negative (missing a rug pull) far outweighs a False Positive. The model is tuned for high Recall — better to over-warn than to let a malicious contract slip past liquidity providers.
